# 🎥 VisionAct AI  
### Real-Time Human Activity Recognition System  

---

## 🚀 Overview  
**VisionAct AI** is a deep learning-based application that detects human activities from video input.  
It processes video frames and predicts the most probable action using a trained neural network model.

This project demonstrates how AI can understand human motion and behavior from video data.

---

## 🎯 Key Features  

- 🎥 Upload video for activity detection  
- 🤖 Deep Learning Model (CNN-based)  
- ⚡ Fast prediction system  
- 📊 Top-5 predictions with confidence scores  
- 🌐 Deployed using Gradio (Hugging Face Spaces)  
- 🎨 Clean and responsive UI  

---

## 🧠 How It Works  

1. User uploads a video  
2. System extracts frames from the video  
3. Frames are resized and normalized  
4. Model predicts probabilities for each class  
5. Top predictions are displayed with confidence
